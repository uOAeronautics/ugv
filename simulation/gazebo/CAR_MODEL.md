# Payload Car Model (`payload_car`)

Default simulated car in `simulation/gazebo/generate.py` since 2026-11-27 (replaces the Freenove
FNK0043 platform; see [`docs/archive/2026-11-27-freenove-car.md`](../../docs/archive/2026-11-27-freenove-car.md)
and [`research/decisions/2026-11-27-replace-freenove-car.md`](../../research/decisions/2026-11-27-replace-freenove-car.md)).

## Source CAD & coordinate frame

- **Original CAD:** `simulation/gazebo/assets/car/payload_assembly/payload_assembly.usdz`
  (byte-identical copy of `Payload Assembly.usdz`, SHA-256 recorded in
  `simulation/gazebo/assets/car/payload_assembly/SOURCE.md`).
- **USD quirks fixed by `convert_payload_usd.py`:**
  - `metersPerUnit = 0.01` (centimetres → metres).
  - Stage metadata declares `upAxis = Y`, while the geometry is physically `+Z` up and `+Y` forward
    (`forward___Y__marker__1_`, `M12_lens__1_` at front `+Y`).
  - Raw assembly is off-origin (wheel hub mean at `(-20.00, +20.00, +0.82) cm`, lowest roller
    vertex at `z = -1.174129 cm`).
- **Gazebo model frame** (matching `simulation/gazebo/assembly.py`):
  - `+X` forward (camera/lens), `+Y` left, `+Z` up, SI metres.
  - Origin `(0, 0, 0)` at the centre of the four wheel hubs projected onto ground contact
    (`z = 0` at the lowest roller vertex).
  - Transform: `x_gz = (y_usd - 20.0) * 0.01`, `y_gz = -(x_usd + 20.0) * 0.01`,
    `z_gz = (z_usd + 1.174129) * 0.01` (`Rz(-90 deg)`).

## Visual meshes & camera-truth gate

Generated by `simulation/gazebo/convert_payload_usd.py` from `1,242` meshes (`1,026,269` triangles):

- Exterior ray-visibility culling drops `766` completely hidden internal CAD meshes (leaving `476`
  visible meshes / `346,963` triangles).
- Per-link quadric edge collapse reduces the model to **`52,000` triangles** (`94.9%` removed):
  `chassis.obj` (`24,000` tris) + 4 local-hub wheel meshes (`7,000` tris each), sharing
  `payload_car.mtl` (`40` USD material colours preserved), plus a combined game-ready PBR master
  `payload_car.glb` (`982 KB`).
- Gated against the full `1,026,269`-triangle CAD with `tools/mesh_opt/meshgate.py` (`--max-tris 60000`):
  - **Seed 0 (`PASS`):** `bbox_mm = 0.0349`, `iou_min = 0.9990`, `depth_p99_mm = 0.0479`,
    `seethrough_pct = 0.0019`, `normal_p90_deg = 5.08°`, `vis_to_cand_p99_mm = 0.0770`,
    `cand_to_orig_p99_mm = 0.1310`, `pierced_mm2 = 0.0000`, `dent_mm2 = 0.3751`,
    `backface_mm2 = 0.5627`.
  - **Seed 42 held-out (`PASS`):** `bbox_mm = 0.0349`, `iou_min = 0.9990`, `depth_p99_mm = 0.0479`,
    `vis_to_cand_max_mm = 0.4834`, `cand_to_orig_max_mm = 0.5021`, `pierced_mm2 = 0.0000`.

## Usage

```sh
cd simulation/gazebo
python3 generate.py                                          # writes static payload_world.sdf (default)
python3 generate.py --drone --output drone_docking_world.sdf # static payload_car + drone
python3 generate.py --room --drone --output lab_docking_world.sdf
python3 generate.py --car freenove                           # archived drivable Freenove model
python3 generate.py --car freenove --drone --output drone_docking_world.sdf
gz sdf -k payload_world.sdf
```

> **Driving / dynamics note:** Until mass and motor parameters are measured, `payload_car` is
> emitted with `<static>true</static>` (geometry/visual and collision model only). Every Gazebo
> drive, control-panel, lockstep, and physics-check tool rejects `payload_car` with an explicit
> error; pass `--car freenove` when regenerating worlds to drive the archived Freenove model.

## Unknown hardware parameters (DO NOT transfer Freenove values)

Everything below is **UNKNOWN** until the physical payload car is bench-characterised (tracked in
`research/tasks/2026-11-27-characterise-payload-car.md`). Because Gazebo silently assigns a `1 kg`
default mass to any dynamic link that omits `<inertial>`, `payload_car_model.py` emits
`<static>true</static>` (a geometry/visual and collision model only) and intentionally omits
`<inertial>`, motor drive plugins, odometry plugins, camera sensors, and IMU sensors when
unmeasured rather than fabricating values or copying Freenove fits:

- **Mass & inertia:** total mass, chassis mass, single-wheel mass, centre of mass, inertia tensor
  (`UNMEASURED_CHASSIS_MASS_KG_TODO` / `UNMEASURED_WHEEL_MASS_KG_TODO` in `payload_car_model.py`).
- **Drive & motor dynamics:** exact N20 gear ratio, stall torque, no-load RPM, deadzone, PWM-to-duty
  curve, TPU 7-roller friction/lateral slip.
- **Electronics & motor driver:** SBC identity/OS (`PCB_56x41`), motor driver IC/bus/pinout,
  current limits, battery voltage telemetry, hardware watchdog path.
- **Camera:** sensor model behind `M12_lens__1_`, resolution/FPS, rolling vs global shutter,
  calibrated intrinsics (`fx`, `fy`, `cx`, `cy`, distortion).
- **IMU:** BNO055 bus/address, operating mode (raw vs NDOF fusion), mounting matrix, resting noise
  and bias drift.
